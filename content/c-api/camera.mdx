# Camera

Where the camera is, and taking it over for intros, boss reveals and scripted scenes.

| Entry | Brief | Status |
|---|---|---|
| [`jfg_camera_get`](/c-api/heroes#jfg_camera_get-) | The camera the hero steers by: position, yaw, pitch | <Status s="built" /> |
| [`jfg_camera_set`](/c-api/heroes#jfg_camera_set-) | Put the camera somewhere this tick | <Status s="built" /> |
| [`jfg_camera_set_distance`](/c-api/heroes#jfg_camera_set_distance-) | The dual-stick camera's distance | <Status s="built" /> |
| `jfg_camera_look_at` | Move the camera to a shot | <Status s="planned" /> |
| `jfg_camera_follow` | Follow an object from an offset | <Status s="planned" /> |
| `jfg_camera_path` | Fly along points | <Status s="planned" /> |
| `jfg_camera_release` | Hand the camera back to the player | <Status s="planned" /> |
| [`jfg_camera_shake`](#jfg_camera_shake-) | Shake the view | <Status s="built" /> |
| `jfg_camera_set_fov` | Field of view | <Status s="planned" /> |
| `jfg_camera_letterbox` | Cinema bars | <Status s="planned" /> |
| `jfg_on_camera_update` | Change the camera each frame | <Status s="planned" /> |
| `jfg_on_cutscene_start`, `jfg_on_cutscene_end` | The game's cutscenes; skip them | <Status s="planned" /> |

<Callout type="info">
While a mod holds the camera, the player keeps control unless the mod also calls `jfg_player_freeze`. Every mod's
camera is released on a level change.
</Callout>

### jfg_camera_get, jfg_camera_set, jfg_camera_set_distance <Status s="built" />

Built with the [Custom heroes](/c-api/heroes#camera) helpers (version 4):

```c
void jfg_camera_get(JfgCameraView* out);           // position, yaw, pitch of the camera the hero steers by
void jfg_camera_set(const JfgCameraSet* camera);   // this tick: position, focus, roll, field of view
void jfg_camera_set_distance(float scale);         // the port's dual-stick camera, further out or in
```

`jfg_camera_set` already does most of what the scripted-camera entries below plan: a mod that sets it every tick
holds the camera, and the game's camera carries on when it stops.

### jfg_camera_shake <Status s="built" />

```c
/**
 * @brief  Shakes the first player's view: hits, blasts, quakes. The view jolts up and down by up to magnitude level
 *         units, fading out over ms milliseconds.
 * @param  magnitude  0-100. The game's strong hits use 15-25 over 2-4 seconds; 5-8 is a light thump.
 * @param  ms         How long it lasts, fading out (at most 10 seconds).
 * @since  6
 * @note   A new call replaces the running shake, 0 stops it, and a level change ends it. It shakes whichever camera is
 *         on: the game's, the dual-stick and aiming views, and a mod's own (jfg_camera_set).
 */
void jfg_camera_shake(int magnitude, int ms);
```

The shake is up and down only, as the game's own. It keeps running while the game is paused, so a shake started
just before a pause is usually over when play resumes. The [Concussion Cannon](/tutorials/charged-weapon#shake-and-recoil)
shakes by how far it was charged:

```c
jfg_camera_shake((int)(3 + 9 * strength), (int)(300 + 700 * strength));   // strength 0.2 .. 1
```


## Example: a boss reveal

```c
static void end_reveal(void* arg) {
    jfg_camera_letterbox(0, 20);
    jfg_camera_release(30);
    jfg_player_freeze(0, 0);
}

static void reveal(JfgObject* boss) {
    JfgVec3 bp, eye;
    jfg_object_get_pos(boss, &bp);
    eye = (JfgVec3){ bp.x, bp.y + 150, bp.z - 400 };
    jfg_player_freeze(0, 1);
    jfg_camera_letterbox(1, 20);
    jfg_camera_look_at(&eye, &bp, 45);
    jfg_timer_after(120, end_reveal, NULL);
}
```
