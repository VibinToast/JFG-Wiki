# Models with no object

19 of the game's 904 models have no object definition and no use in the code. Each is shown in its bind pose and
turning, eight views 45 degrees apart. Not counted: the cheat character's low-detail model (0x384), which has no
definition either but is loaded by the ants cheat (see [Turned out to be used](/unused#turned-out-to-be-used)).
