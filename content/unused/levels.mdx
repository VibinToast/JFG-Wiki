# Levels nothing reaches

## Named "NOT USED"

Three levels say so in their own names:
- **83:** both its object lists are empty.
- **105:** 29 squadrons, exits to 23 and 142.
- **116:** a jetpack test with 8 refuel points.

Tracks 85 and 94 are one-triangle stubs: their geometry was removed.

## Test levels and enemy rooms

- **33:** a character test: tokens, character transformers, an alien door and a hint character.
- **90:** a top-down test with a squadron only. Probably the home of the [flying ship](/unused/code#a-flying-ship-with-a-top-down-camera).
- **108:** 3 Lupus characters.
- **109:** a sewer test level, the only user of track 88 (44 segments).
- **111, 137, 117:** multiplayer prototypes.
- **140:** a world map test.
- **160:** a cooperative maze: 70 squadrons, 151 patrol paths, 15 flame objects.
- **197:** a multiplayer canyon.
- **175-178 and 273,** in world 19: the developers' enemy rooms. Levels 176-178 are on track 90 (floor at y -178),
  and each list holds one squadron of nearly every enemy type, count 1. They are the original settings for each
  type: flyers are placed 84 units above the floor and walkers on it. See [Enemies](/unused/enemies).

In the Japanese version, 33, 90 and 140 are renamed as tests of chests and hint text, collectables, and door
messages, and their lists are filled with those test objects.

## Odd links in levels that are reached

- 56 exits to 112 start point 1, but 112 has only start point 0.
- 61 exits to 65 start point 1: it crosses worlds, and that start point doesn't exist.
- Start points nothing leads to: 8 sp4, 56 sp1, 61 sp1, 168 sp1, 217 sp1, 245 sp1, 316 sp1, 375 sp1 and sp2.

## Other leftovers

- **Tracks used only by levels nothing reaches:** 18, 38, 61, 63, 85, 88, 90, 94, 95, 125, 137, 139, 168, 216.
- **Assets 0x20 and 0x21** are not old level headers. They are a 412-entry names table: each level's name plus three
  strings of editor field text (for example "dome5 / ROTATETIME / 300"). Five entries keep a full name that the level
  header cuts at 31 characters. The Japanese version regenerated it.
- **Cutscene blocks no level uses:** 52, 70, 124 and 327.
