# Windows and tools

Every menu, tool and window in JFG-Studio, in the order you meet them.

## Menus

| Menu | Item | Key | Does |
|---|---|---|---|
| File | New project… | | The [New project](/studio/first-mod#create-the-project) dialog |
| File | Open project… | <kbd>Ctrl+O</kbd> | Pick a `.jfgproj` folder |
| File | Save | <kbd>Ctrl+S</kbd> | Saves the project, levels, planets, kinds, galaxies, and triggers and weapons when changed |
| File | Import geometry… | | Copies a `.glb` into `geometry/` and checks it |
| File | Settings… | | The decomp, port and ROM paths |
| Edit | Undo, Redo | <kbd>Ctrl+Z</kbd> <kbd>Ctrl+Y</kbd> | Per level |
| Edit | Duplicate, Delete | <kbd>Ctrl+D</kbd> <kbd>Delete</kbd> | The selection |
| Edit | Frame selection | <kbd>F</kbd> | The camera frames the selection, or the level from above |
| Window | one item per window, Reset layout | | Show or hide windows; the default layout |
| Help | Open log folder | | Studio's crash logs |
| Build | Validate, Build pack, Play in game | | Check, build `build/<mod id>.nrm`, build and play |

## Toolbar

<Figure src="/img/studio-toolbar.png" alt="The toolbar" caption="Tools on the left; Local, Snap, Floor and the grid size; Play, the hero, Validate." />

| Tool | Key | Does |
|---|---|---|
| Hand | <kbd>Q</kbd> | Pan and orbit only (clicking still selects) |
| Move | <kbd>W</kbd> | Move the selection (any number of objects together) |
| Rotate | <kbd>E</kbd> | Turn one object about the vertical axis, if its type has a facing |
| Scale | <kbd>R</kbd> | Size one object, if its type has a size |
| Region | <kbd>G</kbd> | Click a navigation region's corners on the floor; <kbd>Enter</kbd> or the first corner finishes, <kbd>Backspace</kbd> removes the last, <kbd>Esc</kbd> cancels |
| Water | <kbd>T</kbd> | Drag a rectangle on the floor: a water surface goes into the level's own geometry. **Auto height** puts it 15 above the floor where you start |
| Patrol | <kbd>P</kbd> | Click points of a squad patrol network, each linked to the last; click a point to link to it; <kbd>Esc</kbd> starts a new chain |

- **Local**: the move handles follow the object's facing.
- **Snap**: moves in steps of the grid size, turns in 5.6° steps.
- **Floor**: moved objects drop onto the floor under them, a little above it (8 units for enemies, squads and start
  points, 2 for the rest) so they don't spawn inside a slope.
- **Play**: builds, installs and starts the game in this level at the selected start point (else 0), as the hero
  picked beside it.

## Scene

<Figure src="/img/studio-scene.png" alt="The Scene window" caption="The Scene: the level's geometry, sky and fog, with every object." />

The open level in 3D: your geometry (or a stock track) with textures, vertex light and fog. Water is see-through
blue, lava orange, kill floors red, invisible colliders a wireframe. Objects the catalog has a model for are drawn as
that model; the rest are coloured markers: start points light blue with an arrow, exits orange with their radius,
squadrons red, members pink, doors purple, region corners green, lights yellow. Rings show ranges (a light's reach, a
sound's range); lines join region corners, patrol links, members to their squadron, and squadrons to their doors.

- **Header**: Fog, Invisible colliders and Sky checkboxes, the level and its track, and the fly speed.
- **Select**: click a marker or model; <kbd>Ctrl</kbd>+click adds or removes; drag on empty space for a box.
- **Camera**: right mouse to look, with <kbd>W</kbd><kbd>A</kbd><kbd>S</kbd><kbd>D</kbd>/<kbd>Q</kbd><kbd>E</kbd> to fly
  (<kbd>Shift</kbd> 3×), wheel for speed, middle mouse to pan, <kbd>Alt</kbd>+left drag to orbit.
- **Place**: drag a row from Prefabs into the Scene.
- **Shapes**: objects the game draws as sprites (pickups) or not at all show as a shape: a start point is a capsule
  with a nose the way the hero will face, pickups and keys a floating diamond. A squad that spawns its own members
  (a sentry, flyers, a Tribal to rescue) shows as its enemy, and squads are named by what they hold.
- **Right-click** an object (a click, not a drag) for its menu: frame it, select its whole squad, duplicate, drop
  to the floor, add cover, delete, or for one of the game's objects, revert it.
- In a stock-level edit, the game level's own objects show in a dim blue while they're read-only, and like your
  own once **Edit the game level's objects** is on (Hierarchy).

## Hierarchy

<Figure src="/img/studio-hierarchy.png" alt="The Hierarchy: a squad with members, navigation regions, start points, exits, pickups" caption="Squads with their members under them, regions together, everything else in a list." width={320} />

The open level's objects. Click to select, <kbd>Ctrl</kbd>+click to add, right-click for a menu.

In an edit of one of the game's levels, the objects you added come first, then **The game level's objects**:
- **Read-only** (the default): they're listed grey. You can look at one in the Inspector, or right-click > **Copy
  into the level** to start one of your own from it.
- **Edit the game level's objects** (the checkbox at the top): move, change and remove them like your own. A
  changed one is marked `*`, removed ones are listed under **Removed**, and right-click > **Revert to the game's**
  or **Put back** undoes it.

The project keeps only what you changed, and the pack carries only that, so other mods can change the same level.
Some of the game's levels share an object list: a change shows in each of them.

## Inspector

<Figure src="/img/studio-inspector-key.png" alt="The Inspector for the yellow key" caption="The selected object: its type, name, position and fields." width={345} />

- **Name** is for you only (the game doesn't see it).
- **Transform**: position, and **Drop to floor**.
- **Destination** (exits): **Leads to** any of your levels or a stock level, the **Start point** to arrive at (only
  ones the level has), and **Create return exit**, which adds the way back in your target level. An exit's
  **arg1A** field is 1 by default, as on most of the game's exits: it shows the stats screen when the exit leads into
  another region. Set it to 0 for an exit that shouldn't.
- The type's **fields**: named values are lists, the rest numbers. Dimmed values still come from the stock entry the
  object was copied from. "Partly decoded" means some of the entry's bytes are kept as they are.
- **Entry** (closed): the raw bytes, for checking.

**Door lock lights.** The light on a door frame has no setting for which door or squad it belongs to: it shows the
**nearest door**, and comes on when nothing keeps that door locked any more (its squad is dead, its switch shot).
Select one and the Inspector's **Lights up for** names that door and the squad or switch that locks it; click either
to select it. To tie a light to a squad, give the squad the door's door id and keep the light nearer that door than
any other.

## Level

<Figure src="/img/studio-level.png" alt="The Level window" caption="The open level's settings." width={345} />

- **Name**, **World** (0–15; 15 is free in the stock game) and **Track** (one of your `.glb` files).
- **Planet**: puts the level in that planet's **region**. An exit that leaves the planet then shows the game's
  "Area Cleared" stats screen, and entering the planet shows its name, its galaxy and the continues. The build sets the
  region for you ([Planet regions](/tutorials/planet#planet-regions)). *None* keeps the level out of any region: no
  stats screen, no continues.
- **Music and sound**: a stock tune or one of your OGGs (**Add OGG music…**), and three ambient loops.
- **Sky and fog**: a stock sky or the clear colour, **Fog** with its colour, start, end and third value (the game's
  depth units, 900–1023).
- **Camera and effects**: field of view, light slots, weather, day length, underwater lights, the saved-flag region
  (a planet's levels get theirs from the build), night vision, refraction, blur.

## Project

<Figure src="/img/studio-project.png" alt="The Project window: levels, planets, geometry, dependencies" caption="The project's levels, planets, geometry files and dependencies." />

Click a level to open it. **New level** makes one on your first geometry; **Edit a stock level…** adds to one of
the game's levels (your objects are added; its own stay, or change once you turn on **Edit the game level's
objects** in the Hierarchy).

## Prefabs

<Figure src="/img/studio-prefabs.png" alt="The Prefabs window" caption="Everything you can place: groups, your kinds, and every object type by category." />

- Search by name, hex id or field set. **In stock** shows only types the game's own levels place.
- **Groups**: *Squad, region and locked door*; *Exit and return start point*; *Navigation region*.
- **Pack kinds**: your reskinned types.
- Categories: Pickups, Doors & switches, Lights & effects, Props, Players & exits, Enemies & navigation, and *Other
  (fields not decoded)*, placed as a copy of a stock entry.
- **Start from**: which stock entry the new object copies (its fields you don't set keep the game's values).
- Drag a row into the Scene, or select it and press **Place at view centre**.

## Console

<Figure src="/img/studio-console.png" alt="The Console" caption="Validate, the last build or play output, and every problem." />

**Validate**, the error and warning counts, the last build, play or import-check output, then every problem. Click
one that names an object to select it.

## Level Graph

<Figure src="/img/studio-level-graph.png" alt="The Level Graph" caption="Every level's exits and where they lead; each planet's entry level." />

A list of every level, the exits in it and where they lead, then each planet's entry level. Read-only.

## Planet

<Figure src="/img/studio-planet.png" alt="The Planet window" caption="Planets on the map: place, route, unlock." />

- **New planet**, and the planet to edit.
- **A point of its own** (a new disc and route) or **Take over a stock point**.
- **Galaxy**: the game's, one of yours, or **New galaxy…**; for your galaxies, its name and home planet.
- **Disc**: position, radius, which stock disc it looks like, top colour.
- **Route**: where it leaves from and the stick direction; the build draws the line.
- **Opens**: from the start, with the stock point, once discovered, by a trigger, after another planet is entered or
  completed.
- **Entry level** for Juno, Vela and Lupus.

## Models

Every model the game has an object type for, turnable and zoomable, with its size, triangles and users. Read-only,
for finding the right type.

## Kinds

<Figure src="/img/studio-kinds.png" alt="The Kinds window" caption="A kind: a stock type's model and behaviour with your textures, at your size." width={345} />

**New kind** picks a base type. Then **Size**, **Export base textures** (to paint over; from your ROM, not for
sharing), and per texture slot **Use file** (your `kinds/<kind>/<slot>.png`) or **Base**.

## Triggers

<Figure src="/img/studio-triggers.png" alt="The Triggers window" caption="When … then …, per level." width={345} />

**When** (once per visit unless **Every time**):

| When | Fields | Fires |
|---|---|---|
| level start | | The first tick in the level |
| enter | Area x0 z0 x1 z1 (or **Area from the Scene's selection**) | The hero is inside the box |
| flag | Game flag | That flag is set |
| door opens | Door id | A locked door opens (its squads are dead, its key used) |
| talk | Talker x z, radius, button (or **Talker at the Scene's selection**) | The hero comes close (or presses the button there) |

**Then**:

| Action | Fields | Does |
|---|---|---|
| message | text, seconds | A line on screen |
| lines | one line per row | The next line each time; the last repeats |
| music, music_stop | track | Play or stop one of your OGGs |
| fog | colour, near, far | Fade the fog |
| flag | number, on | Set or clear a game flag |
| unlock_door | door id | Unlock as a squad's death does |
| warp | level, start | Change level |
| spawn | type, x y z, from hero | Create an object (stock types only) |
| unlock planet, complete planet | planet | Open a planet, or complete one so the next opens |

Studio builds the triggers into a Lua script (`scripts/_triggers.lua`).

## Weapons

<Figure src="/img/studio-weapons.png" alt="The Weapons window" caption="Tick a field to change it in this pack." width={345} />

One section per weapon. Tick a field to change it: damage, delay, throw_delay, lifetime, spread_x, spread_y, speed.
See the [Weapons API](/api/weapons) for which weapon uses which field.

## Scripts

<Figure src="/img/studio-scripts.png" alt="The Scripts window" caption="A plain Lua editor, with the API listed below." />

**New script**, one tab per `scripts/*.lua`, and **Save script**. Every `.lua` in `scripts/` goes into the pack. See
[Lua scripting](/api/lua).
