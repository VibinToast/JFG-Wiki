# Jet Force Gemini modding

Make new planets, levels, enemies, music, weapon tuning, scripts and texture packs for
**[Jet Force Gemini: Recompiled](https://github.com/VibinToast/JetForceGemini-Recomp)**, the PC port. Build them in
[JFG-Studio](https://github.com/VibinToast/JFG-Studio), model levels in Blender, or write code against the port's
modding API.

## Three ways to make a mod

| Way | For | You write |
|---|---|---|
| [JFG-Studio](/studio) | Levels, planets, enemies, music, triggers, weapons | Nothing: Studio builds the pack. Lua is optional. |
| [Lua scripts](/api/lua) | Game logic in a pack: messages, doors, spawns, planets, weapons | Lua 5.4, in Studio's Scripts window or any editor |
| [C code mods](/api/c) | Anything else: hook or replace any game function | C, compiled for the N64's CPU |

<Callout type="error">
**Your own copy of the game only.** The tools read your own US ROM. Never share the ROM, Studio's catalog, or
anything exported from them (stock models, textures, tracks). Packs Studio builds carry only your own content plus
references to the game's, which the port fills in from each player's own copy.
</Callout>
